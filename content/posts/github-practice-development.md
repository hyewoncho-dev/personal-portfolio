## 1. 프로젝트 소개



GitHub Practice는 Git과 GitHub의 기본 사용 방법을 익히기 위해 진행한 실습 프로젝트입니다.



Python으로 간단한 기능을 구현하고, Git을 이용해 변경 사항을 관리했습니다. 또한 GitHub 저장소에 코드를 업로드하고 브랜치와 Pull Request를 활용하는 과정을 경험했습니다.



- GitHub Repository: [github-practice2](https://github.com/hyewoncho-dev/github-practice2)



## 2. 주요 실습 내용



이번 실습에서는 기능별로 Python 파일을 나누어 작성했습니다.



- `zero.py`: 0과 관련된 기능

- `mul.py`: 곱셈 기능

- `div.py`: 나눗셈 기능



코드를 작성하는 것뿐만 아니라 변경 사항을 기록하고 관리하는 Git 명령어도 함께 익혔습니다.



## 3. 사용 기술



- **Language:** Python

- **Version Control:** Git

- **Collaboration:** GitHub

- **Workflow:** Git Flow



## 4. Git과 GitHub 활용



실습을 진행하면서 Git과 GitHub를 활용한 기본적인 개발 흐름을 경험했습니다.



1. GitHub 저장소 생성 및 로컬 저장소 연결

2. 기능별 브랜치 생성

3. 브랜치에서 코드 작성 및 수정

4. 변경 사항을 커밋으로 기록

5. GitHub에 브랜치 업로드

6. Pull Request 생성 및 병합



이를 통해 하나의 브랜치에서 모든 작업을 진행하는 대신, 기능별로 작업을 분리하고 변경 사항을 관리하는 방법을 배웠습니다.



## 5. 실습을 통해 배운 점



이번 프로젝트를 통해 Git과 GitHub가 단순히 코드를 저장하는 도구가 아니라 개발 과정에서 변경 사항을 추적하고 협업을 돕는 도구라는 점을 이해했습니다.



특히 브랜치와 Pull Request를 사용하는 과정에서 작업 내용을 분리하고 검토한 뒤 병합하는 흐름을 익힐 수 있었습니다.



처음에는 Git 명령어와 브랜치의 개념이 익숙하지 않았지만, 직접 명령어를 입력하고 결과를 확인하면서 사용 방법을 익혔습니다.



## 6. 마무리



GitHub Practice는 Git과 GitHub의 기본적인 사용 방법을 익히고 실제 개발 흐름을 경험할 수 있었던 프로젝트입니다.



앞으로 진행할 프로젝트에서도 Git을 활용해 코드를 체계적으로 관리하고, 브랜치와 Pull Request를 적극적으로 활용하고자 합니다.
