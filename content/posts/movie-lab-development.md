# Movie Lab 개발 기록



## 1. 프로젝트 소개



Movie Lab은 Vue.js와 TMDB API를 활용하여 영화 정보를 조회하고 검색할 수 있도록 만든 웹 프로젝트입니다.



TMDB에서 제공하는 실제 영화 데이터를 API로 받아와 화면에 표시하는 것을 목표로 했습니다.



프로젝트를 진행하면서 Vue.js의 기본적인 화면 구성 방법과 API 요청 및 응답 데이터를 처리하는 과정을 학습했습니다.



<!--more-->



## 2. 주요 기능



### API 키 입력 및 연결



TMDB API를 사용하기 위해 사용자가 발급받은 API Key를 직접 입력할 수 있도록 구성했습니다.



입력한 키를 이용해 TMDB 서버에 요청을 보내고 영화 데이터를 불러오도록 구현했습니다.



API 키를 소스 코드에 직접 작성하지 않고 브라우저 메모리에서 관리하도록 하여 개인 키가 프로젝트 저장소나 배포 파일에 포함되지 않도록 했습니다.



### 인기 영화 조회



TMDB API의 인기 영화 조회 기능을 활용하여 실제 영화 정보를 화면에 표시했습니다.



영화 카드에는 다음과 같은 정보를 보여주도록 구성했습니다.



- 영화 제목

- 개봉일

- 줄거리

- 평점

- 포스터 이미지



### 영화 검색



사용자가 영화 제목을 입력하고 검색 버튼을 누르면 해당 검색어에 맞는 영화 목록을 불러오도록 구현했습니다.



검색어가 없는 경우에는 인기 영화 목록을 다시 조회하도록 구성했습니다.



### 페이지 이동



검색 결과가 여러 페이지에 걸쳐 표시될 수 있도록 이전 페이지와 다음 페이지 기능을 추가했습니다.



새로운 검색을 시작하면 첫 번째 페이지부터 결과를 확인할 수 있도록 처리했습니다.



### 로딩 및 오류 처리



API 요청 과정에서 발생할 수 있는 상황을 고려하여 로딩, 오류, 검색 결과 없음 등의 상태를 구분해 표시하도록 구성했습니다.



이를 통해 사용자가 현재 데이터 요청이 진행 중인지, 검색 결과가 없는지 확인할 수 있도록 했습니다.



## 3. 사용 기술



- Vue.js: 사용자 인터페이스 구성

- JavaScript: 기능 및 데이터 처리

- TMDB API: 영화 데이터 조회 및 검색

- Vite: 개발 서버 및 프로젝트 빌드

- HTML, CSS: 웹 페이지 구조와 디자인

- Git, GitHub: 소스 코드 관리

- GitHub Actions: 배포 자동화 실습

- GitHub Pages: 정적 웹 페이지 배포



## 4. 배포 과정



Movie Lab은 정적 프론트엔드 웹 애플리케이션으로 구성했습니다.



Vite를 이용해 프로젝트를 빌드하고 생성된 결과물을 GitHub Pages에 배포하는 과정을 경험했습니다.



또한 GitHub Actions를 활용한 배포 과정을 실습하면서 소스 코드 관리뿐만 아니라 웹 프로젝트를 실제 웹사이트로 공개하는 과정도 익힐 수 있었습니다.



## 5. 개발 과정에서 배운 점



이번 프로젝트를 통해 Vue.js에서 화면을 구성하는 방법뿐만 아니라 외부 API와 데이터를 주고받는 과정을 이해할 수 있었습니다.



특히 API 요청을 통해 받아온 JSON 데이터를 화면에 표시하고, 검색어와 페이지 번호에 따라 다른 결과를 불러오는 과정이 인상적이었습니다.



또한 API 키와 같은 개인 인증 정보를 관리할 때는 단순히 기능이 작동하는 것뿐만 아니라 소스 코드와 배포 파일에 민감한 정보가 포함되지 않도록 주의해야 한다는 점을 배웠습니다.



마지막으로 Vite 빌드와 GitHub Pages 배포를 경험하면서 프론트엔드 개발부터 실제 서비스 공개까지의 흐름을 익힐 수 있었습니다.



## 6. 마무리



Movie Lab은 Vue.js와 외부 API를 연결하여 실제 데이터를 활용하는 웹 애플리케이션을 만들어 볼 수 있었던 프로젝트였습니다.



앞으로도 다양한 API를 활용한 웹 프로젝트를 진행하면서 프론트엔드 개발 역량과 데이터 처리 능력을 꾸준히 발전시켜 나가고 싶습니다.



Tech Stack: Vue.js, JavaScript, TMDB API, Vite, HTML, CSS, GitHub Actions, GitHub Pages
