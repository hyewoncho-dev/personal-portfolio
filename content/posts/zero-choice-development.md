# Zero Choice 개발 기록

## 1. 프로젝트 소개

2026 TBM 창업캠프에서 소비자의 가치관을 바탕으로 합리적인 소비 선택을 돕는 애플리케이션 **Zero Choice** 프로젝트에 참여했습니다.

**진행 상태:** 주요 기능 구현 및 개발 완료

**담당 역할:** 프론트엔드 화면 및 사용자 인터랙션 구현, AI 기반 바이브 코딩 활용

Zero Choice는 사용자가 중요하게 생각하는 소비 기준을 먼저 설정하고, 이를 바탕으로 소비 패턴과 상품을 분석하는 서비스입니다.

프로젝트의 슬로건은 다음과 같습니다.

> 고민은 0으로, 당신의 가치는 100으로.

단순히 저렴한 상품을 추천하는 것이 아니라 사용자가 중요하게 생각하는 가치에 맞는 소비를 할 수 있도록 돕는 것이 프로젝트의 핵심 아이디어였습니다.

## 2. 주요 기능

### 소비 가치관 설정

사용자는 다음 세 가지 기준 중 하나를 선택할 수 있습니다.

- 합리적 가성비
- 지속가능한 환경
- 완벽한 밸런스

선택한 가치관은 이후 소비 분석과 상품 추천의 기준이 됩니다.

### 오늘의 소비 분석

사용자의 소비 상태를 확인할 수 있도록 다음과 같은 정보를 제공합니다.

- 이번 달 예산 잔액
- 탄소 절감량
- 소비 안전 지수

### 상품 검색 및 맞춤 추천

사용자가 원하는 상품을 검색하면 설정한 소비 가치관을 바탕으로 상품을 분석하고 추천하는 기능입니다.

### 가치 기준 기반 상품 분석

상품의 가격과 환경 영향 등을 분석하고, 사용자의 소비 기준에 맞는 대체 상품과 예상 절감 금액을 비교할 수 있도록 구성했습니다.

## 3. 나의 역할

이번 프로젝트에서는 Claude를 활용한 바이브 코딩 방식으로 애플리케이션 개발에 참여했습니다.

주요 작업은 다음과 같습니다.

- 온보딩 및 소비 가치관 선택 화면 구현
- 소비 분석과 상품 추천 화면 구현
- 사용자 입력에 따른 화면 인터랙션 구현
- 가치관 설정부터 분석 결과까지 이어지는 서비스 흐름 구현
- Claude에 기능의 요구사항과 동작 조건을 구체적으로 전달하며 개발 진행

## 4. 개발 과정에서 배운 점

이번 프로젝트를 통해 AI를 활용한 개발에서도 개발자의 역할이 중요하다는 것을 느꼈습니다.

처음에는 AI에게 원하는 기능을 설명하고 코드를 생성하는 과정에 집중했습니다. 하지만 실제 개발을 진행하면서 단순히 기능을 요청하는 것만으로는 원하는 결과를 얻기 어려웠습니다.

기능이 어떤 조건에서 동작해야 하는지, 사용자의 입력에 따라 화면이 어떻게 바뀌어야 하는지 등을 구체적으로 정의해야 했습니다.

특히 요구사항을 명확하게 작성할수록 코드 수정 과정이 줄어들고 원하는 기능을 구현하기 쉬워진다는 점을 경험했습니다.

## 5. 마무리

Zero Choice 프로젝트는 AI를 활용한 개발 방식과 사용자 중심의 서비스 설계를 경험할 수 있었던 활동이었습니다.

앞으로도 새로운 기술을 직접 활용하고 다양한 프로젝트에 참여하면서 문제를 정의하고 해결하는 능력을 키워 나가고 싶습니다.
