# Mini Todo 개발 기록

## 1. 프로젝트 소개

웹 개발 학습 과정에서 **React와 Firebase를 활용한 Mini Todo App**을 제작했습니다.

**담당 역할:** 개인 프로젝트 개발 및 주요 기능 구현

**주요 기여:** Firebase Authentication을 이용한 회원가입·로그인과 로그인 상태 관리, Cloud Firestore를 활용한 사용자별 할 일 데이터 관리 구현

Mini Todo는 사용자가 해야 할 일을 등록하고 완료 여부를 관리할 수 있는 할 일 관리 웹 애플리케이션입니다.

단순히 할 일을 추가하고 삭제하는 기능뿐만 아니라, 사용자가 로그인한 후 자신의 할 일 데이터를 관리할 수 있도록 구현하는 것을 목표로 했습니다.

<!--more-->

## 2. 주요 기능

### 회원가입 및 로그인

Firebase Authentication을 활용하여 사용자 인증 기능을 구현했습니다.

사용자가 계정을 생성하고 로그인할 수 있도록 구성했으며, 인증 상태에 따라 서비스를 이용할 수 있도록 했습니다.

### 로그인 상태 유지

페이지를 새로고침하더라도 로그인 상태가 유지되도록 인증 상태를 관리했습니다.

이를 통해 사용자가 매번 로그인하지 않아도 서비스를 이어서 이용할 수 있도록 했습니다.

### 할 일 관리

사용자가 자신의 할 일을 등록하고 관리할 수 있도록 구성했습니다.

- 새로운 할 일 추가
- 할 일 완료 여부 변경
- 등록한 할 일 데이터 관리

### 사용자별 데이터 관리

Cloud Firestore를 활용하여 할 일 데이터를 저장했습니다.

각 사용자의 데이터가 구분되도록 다음과 같은 경로 구조를 사용했습니다.

`/users/{uid}/todos/{todoId}`

로그인한 사용자의 UID를 기준으로 데이터를 관리하여 사용자별 할 일 목록이 분리되도록 구성했습니다.

## 3. 사용 기술

- **React:** 사용자 인터페이스 구성
- **JavaScript:** 기능 및 화면 동작 구현
- **Firebase Authentication:** 회원가입 및 로그인
- **Cloud Firestore:** 할 일 데이터 저장 및 관리
- **Vite:** 개발 환경 및 프로젝트 빌드
- **Git, GitHub:** 소스 코드 관리 및 버전 관리
- **GitHub Actions:** 배포 자동화 실습

## 4. 개발 과정에서 배운 점

이번 프로젝트를 통해 프론트엔드 화면을 구현하는 것뿐만 아니라 사용자 인증과 데이터 저장까지 연결하는 과정을 경험했습니다.

특히 Firebase Authentication으로 로그인 상태를 관리하고, Firestore에 사용자별 데이터를 저장하는 과정에서 인증 정보와 데이터 구조의 관계를 이해할 수 있었습니다.

또한 사용자마다 서로 다른 데이터를 관리하려면 단순히 데이터를 저장하는 것뿐만 아니라 데이터가 저장되는 경로와 접근 권한을 함께 고려해야 한다는 점을 배웠습니다.

개발 과정에서 발생한 오류를 확인하고 수정하면서 React와 Firebase의 동작 방식도 익힐 수 있었습니다.

## 5. 마무리

Mini Todo 프로젝트는 React를 이용한 프론트엔드 개발부터 Firebase를 활용한 인증과 데이터 관리까지 경험할 수 있었던 프로젝트였습니다.

앞으로도 다양한 웹 애플리케이션을 직접 만들어 보면서 사용자 인증, 데이터베이스, 서비스 배포 등 웹 개발에 필요한 기술을 꾸준히 익혀 나가고 싶습니다.

**Tech Stack:** React, JavaScript, Firebase Authentication, Cloud Firestore, Vite, GitHub Actions
