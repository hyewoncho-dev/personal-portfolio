\## 1. Zero Choice



\*\*AI 기반 개인 맞춤형 소비 설계 애플리케이션\*\*



\[GitHub Repository](https://github.com/hyewoncho-dev/TBMCamp2026)



Zero Choice는 사용자의 소비 가치관을 바탕으로 소비 패턴과 상품을 분석하고, 개인의 기준에 맞는 소비 선택을 돕는 애플리케이션입니다.



\### 주요 기능



\- \*\*소비 가치관 설정\*\*

&#x20; - 합리적 가성비, 지속가능한 환경, 완벽한 밸런스 중 소비 기준 선택

\- \*\*오늘의 소비 분석\*\*

&#x20; - 이번 달 예산 잔액, 탄소 절감량, 소비 안전 지수 확인

\- \*\*상품 검색 및 맞춤 추천\*\*

&#x20; - 사용자가 원하는 상품을 검색하고 설정한 가치관에 맞춰 분석

\- \*\*가치 기준 기반 상품 분석\*\*

&#x20; - 상품의 가격과 환경 영향 등을 분석하고 대체 상품 및 예상 절감 금액 제안



\### My Role



\*\*Claude를 활용한 바이브 코딩 방식의 애플리케이션 개발 참여\*\*



\- 서비스의 사용자 흐름을 고려한 온보딩, 가치관 선택, 소비 분석, 상품 추천 화면 구현

\- 소비 가치관 선택과 상품 검색 등 사용자 입력에 따른 인터랙션 구현

\- 가치관 설정부터 분석 결과와 상품 추천까지 이어지는 서비스 흐름 구현

\- Claude에 요구사항과 기능의 동작 방식을 구체적으로 전달하며 개발 진행



\### Tech Stack



Python, Claude AI, Vibe Coding



\### What I Learned



AI를 활용한 개발에서도 개발자가 요구사항과 서비스의 동작 방식을 얼마나 구체적으로 정의하는지가 중요하다는 것을 배웠습니다.



단순히 코드를 생성하도록 요청하는 것이 아니라 세부 조건과 규칙을 명확하게 전달해야 원하는 결과를 얻을 수 있다는 점을 경험했습니다.

\## 2. 교수 리서치 노트



\*\*LLM을 활용한 교수 정보 검색 및 연구 이력 정리 서비스\*\*



\[GitHub Repository](https://github.com/hyewoncho-dev/Hackathon2026)



\[Live Demo](https://hackathone-pied.vercel.app/)



제2회 호남권 SW중심대학사업 LLM 해커톤 경진대회 프로젝트입니다.



대학명과 교수명을 입력하면 공개 웹에서 공식 교수 프로필 후보를 찾고, 사용자가 대상을 확정한 뒤 연구 내용과 주요 이력을 출처와 함께 정리하는 FastAPI 기반 MVP입니다.



\### 주요 기능



\- \*\*교수 정보 검색\*\*

&#x20; - 대학명과 교수명을 입력하여 공개 웹에서 관련 정보 검색

\- \*\*공식 프로필 후보 확인\*\*

&#x20; - 대학의 공식 홈페이지와 교수 디렉터리를 중심으로 정보 확인

\- \*\*연구 정보 수집 및 정리\*\*

&#x20; - 공식 페이지에서 교수의 연구 내용과 주요 이력 추출

\- \*\*출처 기반 정보 제공\*\*

&#x20; - 실제 출처와 근거를 확인한 정보만 저장

\- \*\*논문 정보 연동\*\*

&#x20; - OpenAlex 저자를 사용자가 별도로 확정하면 주요 논문 정보 수집



\### My Role



\*\*Frontend Development\*\*



팀 프로젝트에서 프론트엔드 개발을 담당하여 사용자가 서비스를 직관적으로 이용할 수 있도록 화면을 구성하고 주요 기능의 사용자 인터랙션을 구현했습니다.



\- \*\*화면 설계\*\*

&#x20; - 서비스의 주요 기능과 사용자 흐름을 고려한 화면 구조 및 UI 구성

&#x20; - 사용자가 교수 정보 검색과 결과 확인을 자연스럽게 진행할 수 있도록 화면 설계

\- \*\*인터랙션 구현\*\*

&#x20; - 사용자 입력과 기능 실행에 따른 화면 변화 구현

&#x20; - 서비스 이용 과정에 필요한 사용자 인터랙션 구현

\- \*\*프론트엔드 연동\*\*

&#x20; - 사용자 입력과 검색 결과가 화면에 반영되도록 기능 연결

&#x20; - 서비스의 주요 기능이 하나의 흐름으로 이어지도록 프론트엔드 구현



\### Tech Stack



FastAPI, Python, Gemini, OpenAlex, SQLite, HTML, CSS, JavaScript, Vercel



\### What I Learned



이번 프로젝트를 통해 프론트엔드 개발은 단순히 화면을 만드는 것이 아니라 사용자의 입력과 서비스의 기능을 자연스럽게 연결하는 과정이라는 것을 배웠습니다.



또한 팀 프로젝트를 진행하며 다른 파트에서 구현한 기능을 이해하고 사용자에게 전달하는 과정의 중요성을 경험했습니다.
