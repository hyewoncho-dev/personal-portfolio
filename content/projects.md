## 🛍️ 01. Zero Choice

> AI 기반 개인 맞춤형 소비 설계 애플리케이션

[GitHub Repository](https://github.com/hyewoncho-dev/TBMCamp2026)

사용자의 소비 가치관을 바탕으로 소비 패턴과 상품을 분석하고, 개인의 기준에 맞는 합리적인 소비 선택을 돕는 애플리케이션입니다.

### ✨ 주요 기능

- **소비 가치관 설정** — 가성비, 지속가능성, 균형 등 개인의 소비 기준 선택
- **오늘의 소비 분석** — 예산 잔액, 탄소 절감량, 소비 안전 지수 확인
- **상품 검색 및 맞춤 추천** — 원하는 상품을 검색하고 설정한 가치관에 따라 분석
- **가치 기준 기반 상품 분석** — 가격과 환경 영향 등을 분석하고 대체 상품 및 예상 절감 금액 제안

### 👩‍💻 My Role

**Claude AI를 활용한 바이브 코딩 방식의 개발 참여**

- 온보딩, 가치관 선택, 소비 분석, 상품 추천 화면 구현
- 소비 가치관 선택 및 상품 검색 등 사용자 인터랙션 구현
- 가치관 설정부터 분석 결과와 상품 추천까지 이어지는 사용자 흐름 구성
- Claude에 요구사항과 기능 동작 방식을 구체적으로 전달하며 개발 진행

### 🧰 Tech Stack

`Python` `Claude AI` `Vibe Coding`

### 💡 What I Learned

AI를 활용한 개발에서도 개발자가 요구사항과 서비스의 동작 방식을 구체적으로 정의하는 것이 중요하다는 점을 배웠습니다.

단순히 코드를 생성하도록 요청하는 것보다 세부 조건과 규칙을 명확하게 전달해야 원하는 결과를 얻을 수 있다는 것을 경험했습니다.

## 🔎 02. 교수 리서치 노트

> LLM을 활용한 교수 정보 검색 및 연구 이력 정리 서비스

[GitHub Repository](https://github.com/hyewoncho-dev/Hackathon2026) · [Live Demo](https://hackathone-pied.vercel.app/)

제2회 호남권 SW중심대학사업 LLM 해커톤 경진대회 프로젝트입니다.

대학명과 교수명을 입력하면 공개 웹에서 공식 교수 프로필 후보를 찾고, 사용자가 대상을 확정한 뒤 연구 내용과 주요 이력을 출처와 함께 정리하는 서비스입니다.

### ✨ 주요 기능

- **교수 정보 검색** — 대학명과 교수명을 입력하여 관련 정보 검색
- **공식 프로필 후보 확인** — 대학 공식 홈페이지와 교수 디렉터리를 중심으로 후보 확인
- **연구 정보 수집 및 정리** — 공식 페이지를 기반으로 연구 내용과 주요 이력 정리
- **출처 기반 정보 제공** — 정보의 근거가 되는 출처 확인
- **논문 정보 연동** — 사용자가 확정한 OpenAlex 저자를 바탕으로 논문 정보 수집

### 👩‍💻 My Role

**Frontend Development**

팀 프로젝트에서 프론트엔드 개발을 담당하여 사용자가 서비스를 직관적으로 이용할 수 있도록 화면과 사용자 인터랙션을 구현했습니다.

- **화면 설계** — 서비스의 주요 기능과 사용자 흐름을 고려한 UI 구성
- **검색 화면 구현** — 교수 정보 검색과 결과 확인을 위한 화면 구성
- **인터랙션 구현** — 사용자 입력과 기능 실행에 따른 화면 변화 구현
- **프론트엔드 연동** — 사용자 입력과 검색 결과가 화면에 자연스럽게 반영되도록 기능 연결

### 🧰 Tech Stack

`FastAPI` `Python` `Gemini` `OpenAlex` `SQLite` `HTML` `CSS` `JavaScript` `Vercel`

### 💡 What I Learned

프론트엔드 개발은 단순히 화면을 만드는 것이 아니라 사용자의 입력과 서비스의 기능을 자연스럽게 연결하는 과정이라는 점을 배웠습니다.

또한 팀 프로젝트를 통해 역할을 분담하고 서로 다른 기능을 하나의 서비스로 연결하는 협업의 중요성을 경험했습니다.

## ✅ 03. Mini Todo App

> React와 Firebase를 활용한 할 일 관리 웹 애플리케이션

[GitHub Repository](https://github.com/hyewoncho-dev/mini-todo)

사용자가 할 일을 등록하고 관리할 수 있는 웹 애플리케이션입니다. 사용자 인증과 데이터베이스를 연동하여 개인별 할 일 관리 기능을 구현했습니다.

### ✨ 주요 기능 및 학습 내용

- React를 활용한 사용자 인터페이스 구현
- Firebase Authentication을 이용한 사용자 인증
- Firestore를 활용한 할 일 데이터 저장 및 관리
- 사용자별 데이터 관리 구조 구현
- 로그인 상태 유지 및 데이터 연동 실습

### 🧰 Tech Stack

`React` `JavaScript` `Firebase Authentication` `Firestore` `Vite`

### 💡 What I Learned

React 컴포넌트를 활용한 화면 구성과 Firebase를 이용한 인증 및 데이터 관리 방법을 학습했습니다.

특히 사용자 인증 정보와 데이터베이스를 연결하여 개인별 데이터를 관리하는 구조를 경험했습니다.
